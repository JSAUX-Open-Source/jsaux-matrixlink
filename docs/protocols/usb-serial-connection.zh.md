# USB 串口连接协议（主机侧）

JSAUX PIXEL 点阵屏产品的主机侧 USB 串口组帧说明。  
**不包含**芯片固件内部实现、闪存布局或工厂 ISP/烧录工具协议。

## 物理 / 串口链路

| 项 | 值 |
|----|----|
| 链路 | USB ↔ UART 桥（CDC / 串口类适配器） |
| VID 白名单 | `0x1A86`、`0x4348` |
| PID 白名单 | `0x7523`、`0x5523` |
| 波特率 | `1_000_000` |
| 数据位 | 8N1，无流控 |
| 主机扫描 | 枚举 TTY；仅接受 VID/PID 白名单匹配 |

须同时命中**一个**白名单 VID 与**一个**白名单 PID。

## 标准帧（主机 ↔ 设备）

多字节整数除另行说明外均为**大端**。

| 字段 | 长度 | 值 / 说明 |
|------|------|-----------|
| Header | 2 | `0x44 0x59`（`DY`） |
| TransportType | 1 | `0x01` 控制/会话；`0x02` GIF 数据块 |
| Command | 1 | 见命令表 |
| PayloadLength | 2 | payload 字节数 |
| Payload | N | 随命令定义 |
| CRC16 | 2 | 对前面全部字节做 CRC-16/KERMIT |

### CRC-16/KERMIT

- 初值 `0x0000`
- 反射多项式常量 `0x8408`
- 逐字节、低位优先
- CRC 以大端 `uint16` 追加

应答帧结构相同。主机应对 `frame[:-2]` 重算 CRC 并与尾部两字节比对。

## 主机命令

| 名称 | Transport | Command | Payload | 用途 |
|------|-----------|---------|---------|------|
| 屏幕电源 | `0x01` | `0x01` | `0x01` 开 / `0x00` 关 | 开关输出 |
| 亮度 | `0x01` | `0x02` | 1 字节 | 设置亮度 |
| 内置动画 | `0x01` | `0x21` | 1 字节动画 ID | 播放内置动画 |
| GIF 开始 | `0x01` | `0x04` | `dataSize` BE u32 + `crc32` BE u32 | 开始上传 |
| GIF 分片 | `0x02` | `0x02` | `sequence` BE u16 + 数据 | GIF 分片 |
| GIF 结束 | `0x01` | `0x0B` | `0x01` | 结束并显示 |

### GIF 整体 CRC-32

写入 **GIF 开始** 帧：

- 初值 `0xFFFFFFFF`，多项式 `0xEDB88320`，低位优先，最后按位取反

参考实现默认分片数据长度：**498** 字节（另加 payload 内 2 字节序号）。

## 时序 / 重试（主机策略）

| 参数 | 典型值 |
|------|--------|
| 写超时 | 1000 ms |
| 应答超时 | 1000 ms（结束确认可随体积放大并封顶） |
| 包间隔 | 12 ms |
| 单包重试 | 3 |
| 整次传输重试 | 2 |

## 应答 status（GIF 会话）

status 为匹配应答 payload 的首字节（Transport/Command 需符合预期）：

| 阶段 | Status | 含义 |
|------|--------|------|
| GIF 开始 | `0x00` | 拒绝 |
| GIF 开始 | `0x02` | 内容相同 / 可跳过后续分片 |
| GIF 开始 | 其他 | 继续分片 |
| GIF 分片 | `0x00` | 分片被拒 |
| GIF 结束 | `0x00` | finalize 被拒 |

无应答、截断、CRC 不符、类型不符 → 按可重试链路错误处理。

## 明确不在开源范围

- 芯片固件二进制、bootloader、闪存烧录协议
- 与 DY 组帧无关的供电口启发式等产品电气策略
- 闭源伴生 daemon / 桌面程序本体
