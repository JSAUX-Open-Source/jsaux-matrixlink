JSAUX PIXEL — opensource packaging helpers
==========================================

THIS IS NOT A FULL PRODUCT INSTALLER / NOT AN OUT-OF-BOX RELEASE.

What these helpers do
---------------------
- Install or remove the **Decky plugin sources** from this tip
- Document that closed companion binaries are absent

What they do NOT do
-------------------
- Install the official companion app / Qt runtime / Codex (not in this tip)
- Make the matrix display work by themselves

Without a separately installed official closed companion:
  plugin core features (device status, modes, assets, timers, live sync) WILL NOT WORK.

Desktop entries in this folder:
  - "Install Decky Plugin (opensource).desktop"
  - "Remove Decky Plugin (opensource).desktop"

Plugin sources: ../../decky-plugin/
Protocols:      ../../docs/protocols/
Full product:   official closed release only
